## 🌐 What is VigourCare?
**VigourCare** is a healthcare web platform built for **patients and consumers** to:

✅ Find **nearby doctors & specialists** using location  
✅ Check **current medicine prices** *(GST not included)*  
✅ Make informed decisions before visiting clinics or pharmacies  

Because your time is expensive — unlike this website.

---

## ✨ Key Features
🗺️ **Location-Based Search**  
Find doctors and specialists near you in seconds.

💊 **Medicine Price Lookup**  
View up-to-date medicine prices *(pre-GST, for clarity)*.

🧑‍⚕️ **Patient-Centric Design**  
Clean UI focused on usability, not confusion.

⚡ **Fast & Lightweight**  
No unnecessary animations. Just results.
